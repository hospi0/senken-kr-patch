## 글자 그리기
- `0x06052F7C` 문자열 그리기: 바이트 > 0x7F → 2바이트 글자 16px, 아니면 반각 8px(ASCFONT).
- `0x06052504` 글자 찾기: SJIS→JIS, 첫 바이트별 시작 칸이 **코드에 박힌 상수**, 거기서 끝(0x733)까지 순차 검색. 글꼴은 저 RAM `0x280200`.
- → **코드 안 고치고 글꼴 그림만 한글로 덮으면 된다**(1,843칸 = 가나·한자 전부 덮기). 칸 코드·순서는 그대로 둘 것.
